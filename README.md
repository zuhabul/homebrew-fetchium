# homebrew-fetchium

Homebrew tap for [Fetchium](https://github.com/zuhabul/Fetchium) — the universal retrieval layer for humans and AI agents.

## Install

```bash
brew install zuhabul/fetchium/fetchium
```

Or tap first:

```bash
brew tap zuhabul/fetchium
brew install fetchium
```

The formula is auto-updated on every release by the Fetchium CI pipeline.
